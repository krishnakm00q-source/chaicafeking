# Chai Cafe King Demo Website

Open `index.html` in a browser.

Included:
- Responsive modern café landing page
- Real supplied café/menu photos
- Menu tabs with prices from the supplied menu cards
- Zomato and Swiggy order buttons
- Google listing button using the link supplied in the request
- Mobile-friendly layout

This is a demo, so menu prices, outlet details, phone number, hours, logo and social links can be updated before publishing.
